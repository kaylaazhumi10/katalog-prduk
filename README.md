# Katalog Produk UPI Store

Aplikasi desktop sederhana untuk mengelola katalog produk (Create, Read, Update, Delete) dengan antarmuka yang bersih dan mudah digunakan.

## Fitur Utama

1. **Tambah Produk (Create)**
   * Pengguna dapat memasukkan **Nama produk**, **Harga (Rp)**, dan memilih **Foto contoh** melalui dropdown yang tersedia (`roti.png`, dll.).
   * Menekan tombol **Simpan** akan menyimpan data produk ke dalam sistem dan menampilkan notifikasi *"Produk berhasil disimpan."* serta memperbarui total jumlah produk.

2. **Lihat Katalog (Read)**
   * Setiap produk yang tersimpan ditampilkan dalam bentuk kartu (*card*) katalog yang memuat gambar produk, nama produk, harga, serta nomor **ID** unik.

3. **Edit Produk (Update)**
   * Setiap kartu produk dilengkapi dengan tombol **Edit**.
   * **Cara Kerja:** Saat tombol **Edit** diklik, data produk terkait (Nama produk, Harga, dan Foto contoh) akan dimuat kembali ke dalam form input di bagian atas. Pengguna dapat mengubah informasi yang diinginkan lalu menekan tombol **Simpan** (atau *Update*) untuk memperbarui data produk berdasarkan ID tersebut tanpa membuat data duplikat.

4. **Hapus Produk (Delete)**
   * Setiap kartu produk dilengkapi dengan tombol **Hapus**.
   * **Cara Kerja:** Saat tombol **Hapus** diklik, sistem akan menghapus data produk tersebut dari daftar penyimpanan berdasarkan ID produk. Kartu produk akan hilang dari tampilan katalog dan indikator **Jumlah produk** di bagian atas akan otomatis berkurang.
